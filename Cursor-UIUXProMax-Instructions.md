# Инструкция: разработка сайта в Cursor с навыком UI/UX Pro Max

## 1. Установка навыка UI/UX Pro Max в Cursor

1. Открыть терминал внутри проекта (папка с будущим сайтом БОКСМАРТ).
2. Установить CLI-инструмент навыка глобально:
   ```
   npm install -g uipro-cli
   ```
3. Перейти в папку проекта и инициализировать навык для Cursor:
   ```
   cd /путь/к/проекту-boxmart
   uipro init --ai cursor
   ```
4. После этого в проекте появится папка правил (`.cursor/rules` или аналог), которая регистрирует навык как Rules-файл — Cursor будет автоматически подключать дизайн-базу при генерации UI-кода.

## 2. Как вызвать навык в самом Cursor

Специальной команды вызывать не нужно — навык активируется автоматически, когда запрос касается UI/UX. Достаточно открыть чат с AI-агентом в Cursor и описать задачу обычным языком, упомянув, что речь о лендинге/сайте.

## 3. Готовый промпт (вводные) для навыка

Скопируйте и вставьте в чат Cursor следующий промпт целиком — он содержит контекст задачи и ссылку на файл ТЗ:

```
Изучи файл BoxMart-Website-TZ.md в проекте — это полное техническое задание на сайт-визитку производства картонных коробок ООО «БОКСМАРТ» (Минск).

Задача: создай современный, продающий B2B-лендинг на основе этого ТЗ.

Контекст продукта: производство гофрокартонных коробок, целевая аудитория — малый бизнес и селлеры маркетплейсов (Wildberries, Ozon).

Стиль: промышленный минимализм, строгий корпоративный B2B-дизайн, много воздуха, акцент на цифрах и фактах. НИКАКИХ фотографий людей и стоковых изображений — используй 3D-рендеры коробок в изометрии, векторные схемы раскроя FEFCO, макротекстуры гофрокартона, минималистичные линейные иконки.

Технологии: [указать: HTML+Tailwind / React+Tailwind / Vue — выбрать по своему стеку].

Собери дизайн-систему под индустрию "manufacturing/B2B packaging" — подбери палитру, типографику и паттерны лендинга под эту тематику, затем сгенерируй код структуры сайта согласно разделу 3 файла ТЗ (Header, Hero, О нас, Каталог FEFCO, Для селлеров маркетплейсов, Калькулятор, FAQ, Footer).

Блок калькулятора (раздел 4 ТЗ) верстай как отдельный компонент, который в будущем будет обращаться к внешнему API (не встраивай формулы расчёта в этот код — только интерфейс с полями и заглушкой fetch-запроса на /api/calculate).
```

## 4. Дополнительная настройка (опционально)

Чтобы сохранить сгенерированную дизайн-систему для единообразия по всем страницам:
```
python3 .cursor/skills/ui-ux-pro-max/scripts/search.py "industrial B2B packaging manufacturer" --design-system --persist -p "BoxMart"
```
Это создаст файл дизайн-правил в `design-system/boxmart/`, на который Cursor будет ссылаться при генерации всех последующих страниц и компонентов.

## 5. Порядок работы в Cursor (пошагово)

1. Создать новую папку проекта, открыть её в Cursor.
2. Положить в корень проекта файлы `BoxMart-Website-TZ.md` и `BoxMart-API-TZ.md`.
3. Выполнить установку навыка (раздел 1 этой инструкции).
4. Вставить промпт из раздела 3 в чат агента Cursor.
5. Проверить сгенерированную структуру, попросить агента доработать конкретные секции при необходимости (например: "перепиши секцию Hero, сделай заголовок короче").
6. После готовности фронтенда — передать `BoxMart-API-TZ.md` тому же или другому агенту/разработчику для реализации backend-части.
