# Техническое задание
## Разработка сайта-визитки для ООО «БОКСМАРТ»
### Производство картонных коробок и гофротары в Минске

**Версия документа:** 1.0
**Дата:** 28 июля 2026

---

## 1. Общие сведения и концепция сайта

Сайт-визитка представляет собой современный, конверсионный одностраничный веб-ресурс (Landing Page), ориентированный на B2B-клиентов и селлеров маркетплейсов (Wildberries, Ozon).

**Главная задача сайта:**
- Продемонстрировать производственные возможности предприятия.
- Описать конкурентные преимущества прямого сотрудничества с производителем.
- Предоставить клиентам интерактивный инструмент для мгновенного самостоятельного расчета стоимости коробок.
- Собрать заявку и передать её менеджерам через Email и Telegram.

---

## 2. Требования к дизайну и визуалу

**Стиль:** Промышленный минимализм, строгий корпоративный B2B-дизайн. Чистая типографика, много воздуха, акцент на цифрах и фактах.

**Запреты (критично):**
- Запрещены изображения людей любого рода (рукопожатия, менеджеры, курьеры, "счастливые клиенты").
- Запрещены типовые стоковые фотографии (склады, конвейеры из фотобанков).

**Разрешенный и рекомендуемый визуал:**
- 3D-рендеры картонных коробок в изометрии (аналогично визуализации в BoxCalc).
- Макрофотографии текстуры гофрокартона (срез волны, крафт-поверхность).
- Векторные чертежи и схемы раскроя FEFCO (линии реза, беговки, клапаны).
- Минималистичные линейные иконки в едином стиле (одна цветовая палитра, один stroke-width).

## 4. ТЗ на встроенный пользовательский калькулятор

### 4.1. Интерфейс и логика полей
Динамический список позиций. По умолчанию — одна карточка (Позиция №1). Под списком — кнопка `+ Добавить позицию`.

Поля ввода для каждой позиции:
- Длина (мм)
- Ширина (мм)
- Высота (мм)
- Желаемый тираж (шт.)

### 4.2. Расчетные данные (вывод для каждой позиции)
В реальном времени отображаются:
1. **Внутренний объем коробки** — формула `(Д × Ш × В) / 1 000 000`, вывод в литрах, округление до 1 знака после запятой.
2. **Цена за 1 шт.** — расчет по упрощенной модели площади × тариф за м². Приписка: `*цена без НДС`.
3. **Итого за тираж** — `Цена за 1 шт. × Тираж`. Приписка: `*цена без НДС`.
4. **Кнопка удаления позиции** (недоступна, если позиция единственная).

### 4.3. Специальное условие для позиции 600×400×400 мм
- **Условие:** Д=600, Ш=400, В=400 (в любом порядке ввода полей).
- **Действие:** скрыть поля «Цена за 1 шт» и «Итого за тираж».
- **Текст:** «Это специальная розничная позиция. Пожалуйста, позвоните или напишите нам, и мы предложим вам наиболее актуальную и выгодную цену.»

### 4.4. Итоговый блок калькулятора
- **Общая сумма заказа без НДС** — сумма всех позиций (кроме 600×400×400).
- **Общая сумма заказа с НДС** — сумма с добавлением 20% НДС.
- **Кнопка** `Оформить заявку`.

### 4.5. Модальное окно оформления заявки
При нажатии «Оформить заявку» открывается модальное окно:
- **Сводка заказа:** список позиций (Д×Ш×В, тираж, цена/шт, стоимость позиции); позиция 600×400×400 — с пометкой «Цена по запросу».
- **Итог:** сумма без НДС и сумма с НДС.
- **Форма:**
  - Имя (обязательно)
  - Телефон (обязательно, маска `+375 (XX) XXX-XX-XX`)
  - Email (необязательно)
  - Комментарий менеджеру (необязательно, `textarea`)
- **Кнопка** `Отправить заказ` → после успеха: «Спасибо за заявку! Наш менеджер свяжется с вами в течение 15 минут».

### 4.6. Интеграция и отправка данных
- **Email:** отправка через SMTP-сервис или PHP-скрипт на корпоративный email.
- **Telegram:** отправка через Webhook в n8n (см. раздел 6).

## 6. Инструкция по настройке Telegram-бота через n8n (Webhook)

**Шаг 1. Создание бота**
1. В Telegram найти `@BotFather`, отправить `/newbot`.
2. Указать имя (например `Boxmart Sales Bot`) и username, заканчивающийся на `_bot`.
3. Сохранить API Token.

**Шаг 2. Настройка n8n**
1. Создать Workflow, добавить ноду **Webhook** (Method: POST, Path: `boxmart-new-order`).
2. Добавить ноду **Telegram** (Operation: Send Message), подключить Token от BotFather.
3. Указать Chat ID менеджеров.
4. Настроить текст сообщения с маппингом полей из Webhook (имя, телефон, комментарий, состав заказа, суммы без/с НДС).
5. Перевести Workflow в статус **Active**, использовать Production URL.

**Шаг 3. Код на сайте (пример для разработчика)**
```javascript
fetch('ВАШ_N8N_WEBHOOK_URL', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: "Иван",
    phone: "+375291112233",
    comment: "Нужно срочно",
    items: "1. 600x400x400, 100 шт...",
    total_no_vat: 150.00,
    total_vat: 180.00
  })
});
```
